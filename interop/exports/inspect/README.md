# Inspect AI exports

Generated by [`interop/inspect_export.py`](../../inspect_export.py). Regenerate with:

```bash
python -m interop.inspect_export boundary_permission
```

| File | What it is |
|---|---|
| `boundary_permission_dataset.jsonl` | 40 cases as Inspect `Sample` objects. `json_dataset()` reads it directly. |
| `boundary_permission_task.py` | Task stub: this dataset + a deterministic scorer, solver left as a placeholder for **your** agent. |
| `boundary_permission_*.eval.json` | One eval log per arm, 120 runs each. `inspect view` reads them. |

```bash
pip install inspect-ai
inspect view --log-dir .
inspect eval boundary_permission_task.py --model <your-model>
```

These are committed rather than left under the gitignored `outputs/` because the point of the export is that somebody outside this repository can pick them up. Full method, and what the export deliberately does not do: [`docs/interop_inspect.md`](../../../docs/interop_inspect.md).
